# TrueNote

## Turn Messages Into Moments ✨

TrueNote is an interactive digital messaging web application that allows users to create personalized messages and turn them into memorable experiences.

Instead of sending a simple text message, users can customize how their message is revealed using animations, themes, countdowns, password protection, and other interactive features.

## Features

### 💌 Create Personalized Messages
Users can create custom messages by adding:

- Sender name
- Recipient name
- Occasion
- Message title
- Personalized message content

Available occasions include:

- Birthday
- Congratulations
- Friendship
- Love
- Apology
- Motivation
- Custom occasions

### ✨ Interactive Reveal Effects

Messages can be displayed using different reveal styles, including:

- Tap to Reveal
- Typing Animation
- Envelope
- Card Flip
- Scratch

### 🎉 Message Effects

Users can enhance their messages with visual effects such as:

- Confetti
- Hearts
- Sparkles
- Petals

### 🎨 Custom Themes and Fonts

Users can personalize the appearance of their messages by selecting different:

- Themes
- Fonts
- Styles

### 🔒 Password Protection

Messages can optionally be protected with a secret password, allowing only the intended recipient to view the message.

### ⏰ Countdown Timer

Users can add a countdown timer to reveal a message at a scheduled time.

### 🎵 Background Music

Background music can be added to create a more engaging and emotional message experience.

### 👀 Live Preview

The application provides a live preview while creating the message, allowing users to see how the final message will appear.

### 🔗 Shareable Message Links

After creating a message, users receive a unique shareable link.

The message can be shared easily, and the application also provides a QR code option.

## Application Flow

1. Create a personalized message
2. Enter sender and recipient details
3. Select an occasion
4. Add a title and message
5. Choose a reveal animation
6. Customize effects, theme, and font
7. Optionally add password protection, a countdown timer, or background music
8. Preview the message
9. Generate and share a unique link
